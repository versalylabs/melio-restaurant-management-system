# Phase 31 – Luxury Customer Website Landing Page

Updated the customer-facing restaurant website landing page to feel more premium and editorial while preserving the existing orange/warm color scheme.

## Changes
- Hero section now uses the restaurant's existing Supabase menu image as a full-width photographic background when available.
- Added layered dark overlays for readability without changing the established color palette.
- Reworked hero typography, spacing and CTAs for a refined fine-dining feel.
- Added a subtle featured-dish panel over the hero image.
- Refined menu presentation with larger photography and more editorial spacing.
- Refined the experience/about section and retained existing ordering functionality.
- Refined the visit/contact section.
- Existing dark mode, branch selection, menu search, category filtering and online ordering links remain intact.

## Image behavior
The website does not require a new image hosting system. It uses the menu image already returned by the public menu API (including Supabase-hosted menu images). If no menu image is available, a branded gradient fallback is displayed.
